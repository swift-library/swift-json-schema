# Changelog

## Unreleased

- **Breaking**: Require Swift 6.3 or later. The package and its command-line product require iOS 18 or macOS 15; shared Apple CI uses Xcode 26.6.

## 0.1.1

- Allow SwiftSyntax 602, 603 and 604 without raising the Swift compiler minimum.

## 0.1.0

- Ordered, lossless JSON values, strict parsing, canonical serialization, and Codable conversion.
- Schema compilation, reference resolution, validation, and structured output for five JSON Schema drafts.
- URI references preserve fragments for URNs and hierarchical identifiers.
- A schema DSL, Schemable macros, Foundation conversions, guided generation, and a command-line validator.
