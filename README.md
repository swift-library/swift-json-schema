# swift-json-schema

A Swift library.

## Install

```swift
.package(url: "https://github.com/swift-library/swift-json-schema.git", .upToNextMinor(from: "0.1.0"))
```

Import `JSONValue` from the corresponding product.

## Requirements

iOS 18+, macOS 15+, Swift tools 6.0+. The package maintains the three
most recent stable system generations independently of compiler requirements.

## Maintenance

[Version and release policy](Documentation/Architecture/VersioningAndRelease.md)
owns compatibility and release acceptance and follows the
[swift-library versioning standard](https://github.com/swift-library/.github/blob/master/VERSIONING.md). Run `Scripts/check`
before submitting changes.
