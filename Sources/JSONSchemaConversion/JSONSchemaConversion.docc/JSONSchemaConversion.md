# ``JSONSchemaConversion``

Decode validated JSON into Foundation values.

@Metadata {
    @PageImage(purpose: icon, source: "jsonschemaconversion-icon", alt: "swift-json-schema logo")
    @PageColor(purple)

Use ``FoundationSchema`` for URL, UUID, date, decimal, and data conversions. Extraction checks the wire representation and fails when the destination cannot represent the value.
