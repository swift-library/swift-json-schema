# ``JSONSchemaFoundationModels``

Convert supported JSON Schema shapes into Foundation Models schemas.

@Metadata {
    @PageImage(purpose: icon, source: "jsonschemafoundationmodels-icon", alt: "swift-json-schema logo")
    @PageColor(purple)
}

Build generation schemas and object-shaped tool inputs with ``GenerationBridge``. The bridge requires iOS 26 or macOS 26 and a Foundation Models SDK. It throws for unsupported keywords or shapes; validate generated content with the original JSON Schema.
