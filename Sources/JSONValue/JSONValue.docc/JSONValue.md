# ``JSONValue``

Parse, inspect, and serialize JSON with exact numbers and ordered object members.

@Metadata {
    @PageImage(purpose: icon, source: "jsonvalue-icon", alt: "swift-json-schema logo")
    @PageColor(purple)
}

Use ``JSONValue`` independently of schema validation. Compact and pretty serialization preserve number tokens; canonical serialization uses binary64 semantics and UTF-16 key ordering.
